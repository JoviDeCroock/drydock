# Code of Conduct

## Our standards

We want this project to be useful to maintainers, security reviewers, and
self-hosters. Keep discussions technical, specific, and respectful.

Expected behavior:

- Be direct about bugs, risks, and tradeoffs without attacking people.
- Assume good intent, but ask for clarification when a change could weaken a
  security boundary.
- Respect private disclosure for vulnerabilities and sensitive operational
  details.
- Keep issues and pull requests focused on actionable project work.

Unacceptable behavior:

- Harassment, threats, insults, or discriminatory language.
- Publishing private information, secrets, exploit details, or vulnerability
  reports outside the private disclosure path in [`SECURITY.md`](SECURITY.md).
- Sustained disruption of maintainers, contributors, or users.

## Enforcement

Maintainers may remove comments, close issues or pull requests, block accounts,
or take other reasonable action when behavior is harmful to the project or its
community.

If you need to report a conduct issue, contact the maintainers privately at
`drydock@drydock.org`. Security vulnerabilities should use the separate
process in [`SECURITY.md`](SECURITY.md).
